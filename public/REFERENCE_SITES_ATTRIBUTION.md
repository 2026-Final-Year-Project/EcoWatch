# Reference mining candidates

`reference-mining-sites.geojson` is derived from the confirmed entries in the
GalamseyWatch public mining-site index. GalamseyWatch is MIT licensed,
Copyright 2026 Samuel Donkor. The layer is a reference-candidate index, not an
EcoWatch prediction or allegation; every selection must be analysed by the
EcoWatch model before any action is considered. The underlying Earthrise data
may have separate terms that must be followed when deploying publicly.
